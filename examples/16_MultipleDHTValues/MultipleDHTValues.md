# Шістнадцятий приклад: кілька значень з одного DHT11

Цей приклад показує, як з одного DHT11 отримати два окремі логічні сенсори і передати їх на Amperia Multimeter.

Замість одного значення (`температура` або `вологість`) ми створюємо два незалежні сенсори в `NSensors`:

- `Temperature` з одиницями `C`
- `Humidity` з одиницями `%`

## Потрібне обладнання

Для запуску прикладу потрібне таке обладнання:

1. Arduino UNO R4 WiFi,
2. EdPro Amperia Shield,
3. DHT11,
4. USB-кабель для живлення/завантаження коду,
5. Amperia Multimeter.

## Як підключити обладнання

1. З'єднайте Arduino UNO R4 WiFi та EdPro Amperia Shield згідно з інструкцією.
2. Підключіть DHT11:
   - `VCC -> 5V` або `3.3V`,
   - `GND -> GND`,
   - `DATA -> A1`.
3. Підключіть Amperia Multimeter до роз'єму `MULTIMETER` на EdPro Amperia Shield.
4. Підключіть Arduino до ноутбука чи комп'ютера за допомогою USB-кабеля.
   - Не змінюйте підключення обладнання, поки воно підключене до живлення.
   - Після підключення Arduino з'явиться в системі як послідовний порт, наприклад `COM8` у Windows або `/dev/ttyACM0` у Linux.

## Що робить цей приклад

1. Ініціалізує DHT11 через `dht.begin()`.
2. Створює об'єкт `NSensors measurements("DHT11")`.
3. Додає два логічні сенсори через `addSensor()`:
   - `Temperature` / `C`
   - `Humidity` / `%`
4. Встановлює для обох однаковий період оновлення через `setDataPeriodMs()`.
5. У `loop()` зчитує температуру і вологість через `dht.readTemperature()` і `dht.readHumidity()`.
6. Оновлює кожне значення через `measurements.set()`.
7. Передає їх на мультиметр через `measurements.publish()`.

`NSensors` дозволяє одного фізичного датчика розбити на кілька логічних сенсорів. Це дуже корисно, якщо один пристрій вимірює кілька параметрів одночасно, але вони мають з'являтися в мультиметрі як окремі канали даних.
