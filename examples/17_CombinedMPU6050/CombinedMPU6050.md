# Сімнадцятий приклад: комбінований MPU6050

Цей приклад показує, як з одного MPU6050 створити кілька логічних сенсорів різної розмірності і передати їх на Amperia Multimeter.

У цьому прикладі:

- `Acceleration` містить три компоненти: `X`, `Y`, `Z`;
- `Magnitude` — це скалярна величина модуля вектора прискорення.

Це типова ситуація для датчиків руху, коли один чип видає векторні дані, а користувачу потрібні як окремі осі, так і загальна величина.

## Потрібне обладнання

Для запуску прикладу потрібне таке обладнання:

1. Arduino UNO R4 WiFi,
2. EdPro Amperia Shield,
3. MPU6050,
4. USB-кабель для живлення/завантаження коду,
5. Amperia Multimeter.

## Як підключити обладнання

1. З'єднайте Arduino UNO R4 WiFi та EdPro Amperia Shield згідно з інструкцією.
2. Підключіть MPU6050 до шини I2C Arduino:
   - `VCC -> 3.3V` або `5V` (залежно від модуля),
   - `GND -> GND`,
   - `SCL -> SCL`,
   - `SDA -> SDA`.
3. Підключіть Amperia Multimeter до роз'єму `MULTIMETER` на EdPro Amperia Shield.
4. Підключіть Arduino до ноутбука чи комп'ютера за допомогою USB-кабеля.
   - Не змінюйте підключення обладнання, поки воно підключене до живлення.
   - Після підключення Arduino з'явиться в системі як послідовний порт, наприклад `COM8` у Windows або `/dev/ttyACM0` у Linux.

## Що робить цей приклад

1. Ініціалізує `MPU6050` через `imu.initialize()`.
2. Створює об'єкт `CombinedSensor measurements("MPU6050")`.
3. Додає логічний сенсор `Acceleration` з трьома компонентами X/Y/Z через `addSensor("Acceleration", "g", "X", "Y", "Z")`.
4. Додає другий сенсор `Magnitude` через `addSensor("Magnitude", "g")`.
5. Читає значення акселерометра `ax`, `ay`, `az` через `imu.getAcceleration(...)`.
6. Перетворює їх у одиниці g за допомогою `accelerationScale`.
7. Обчислює модуль вектора прискорення:
   - `sqrt(ax^2 + ay^2 + az^2)`
8. Записує нові значення у `CombinedSensor` і публікує їх на мультиметр.

`CombinedSensor` дозволяє одному пристрою видавати дані різної розмірності в одному потоці. Це корисно для сенсорів, які повертають як векторні величини, так і їх скалярні характеристики.

У цьому прикладі один і той самий `MPU6050` одночасно подає:
- тривимірний вектор прискорення,
- загальну величину цього вектора.
