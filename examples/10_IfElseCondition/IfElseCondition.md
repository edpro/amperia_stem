# Десятий приклад: логіка if / else для CO2

Цей приклад показує, як зчитувати рівень CO2 з EdPro Sensor, порівнювати його з порогом і керувати світлодіодом залежно від результату.

Він демонструє просту логіку умов: якщо виміряне значення перевищує заданий поріг, LED вмикається; інакше — вимикається.

## Потрібне обладнання

Для запуску прикладу потрібне таке обладнання:

1. Arduino UNO R4 WiFi,
2. EdPro Amperia Shield,
3. Qwiic-кабель для з'єднання Arduino UNO R4 WiFi з EdPro Amperia Shield,
4. EdPro CO2 Sensor,
5. LED,
6. USB-кабель для живлення/завантаження коду,
7. Amperia Multimeter.

## Як підключити обладнання

1. З'єднайте Arduino UNO R4 WiFi та EdPro Amperia Shield згідно з інструкцією.
2. З'єднайте Qwiic-роз'єми Arduino UNO R4 WiFi та EdPro Amperia Shield кабелем Qwiic.
3. Підключіть EdPro CO2 Sensor до роз'єму `SENSOR` на EdPro Amperia Shield.
4. Підключіть LED:
   - один контакт до `A0`,
   - інший контакт до `GND`.
5. Підключіть Amperia Multimeter до роз'єму `MULTIMETER` на EdPro Amperia Shield.
6. Підключіть Arduino до ноутбука чи комп'ютера за допомогою USB-кабеля.
   - Не змінюйте підключення обладнання, поки воно підключене до живлення.
   - Після підключення Arduino з'явиться в системі як послідовний порт, наприклад `COM8` у Windows або `/dev/ttyACM0` у Linux.

## Що робить цей приклад

1. Ініціалізує інтерфейс для читання CO2 Sensor через `sensors.begin()`.
2. Знаходить сенсор `CO2` за його ім'ям через `sensors.findSensor("CO2")`.
3. Отримує його поточне значення через `getCO2()`.
4. Порівнює значення з порогом `2000`.
5. Якщо значення більше за поріг, вмикає LED через `digitalWrite(ledPin, HIGH)`.
6. Інакше вимикає LED через `digitalWrite(ledPin, LOW)`.
7. Виводить значення в Serial Monitor і публікує його на мультиметр через `display.publish()`.

Цей приклад показує, як зчитані значення можна використовувати для реального управління пристроєм на основі умови.

Така логіка часто використовується в системах моніторингу, автоматизації, сигналізації або індикації стану пристрою.
