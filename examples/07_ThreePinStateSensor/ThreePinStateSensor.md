# Сьомий приклад: 3-піновий тестер стану

Цей приклад показує, як зчитувати стан трьох логічних входів і передавати їх у систему Amperia як незалежні значення.

Код підходить для перевірки стану кнопок, датчиків, перемикачів або сигналів, які можуть бути у станах `HIGH` або `LOW`.

## Потрібне обладнання

Для запуску прикладу потрібні:

1. Arduino UNO R4 WiFi,
2. EdPro Amperia Shield,
3. три сигнальні лінії або джерела логічного рівня,
4. USB-кабель для завантаження коду,
5. Amperia Multimeter.

## Як підключити обладнання

1. Підключіть Arduino UNO R4 WiFi до EdPro Amperia Shield.
2. Підключіть три сигнальні лінії до пінів:
   - `D2`
   - `A0`
   - `A1`
3. Для перевірки можна використовувати кнопки, перемикачі або інші логічні джерела сигналу.
4. Підключіть Amperia Multimeter до роз'єму `MULTIMETER` на платі.

## Що робить цей приклад

1. Створює сенсор `NDimSensor` з трьома каналами.
2. Визначає функцію `readLogicLevel(pin)`, яка повертає `1` для `HIGH` і `0` для `LOW`.
3. У `setup()` налаштовує три входи як `INPUT_PULLUP`.
4. У `loop()` читає стан кожного входу та публікує його в Amperia Multimeter.
5. Кожен канал представляє окремий логічний сигнал.
