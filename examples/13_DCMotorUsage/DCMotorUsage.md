# Тринадцятий приклад: використання DC-двигуна

Цей приклад показує, як керувати DC-двигуном через `AmpDC`:

- обертати вперед,
- обертати назад,
- зупиняти двигун.

Під час виконання програма послідовно змінює напрямок обертання і демонструє базові команди керування двигуном.

## Потрібне обладнання

Для запуску прикладу потрібне таке обладнання:

1. Arduino UNO R4 WiFi,
2. EdPro Amperia Shield,
3. DC-двигун,
4. USB-кабель для живлення/завантаження коду.

## Як підключити обладнання

1. З'єднайте Arduino UNO R4 WiFi та EdPro Amperia Shield згідно з інструкцією.
2. Підключіть DC-двигун до відповідного каналу `DC MOTOR` на EdPro Amperia Shield.
3. Підключіть Arduino до ноутбука чи комп'ютера за допомогою USB-кабеля.
4. Після підключення Arduino з'явиться в системі як послідовний порт, наприклад `COM8` у Windows або `/dev/ttyACM0` у Linux.

## Що робить цей приклад

1. Ініціалізує двигун через `motor.begin()`.
2. У циклі `loop()` запускає двигун вперед через `motor.setSpeed(200)`.
3. Потім змінює напрямок на назад через `motor.setSpeed(-200)`.
4. Після цього зупиняє двигун через `motor.stop()`.
5. Кожна дія триває 2 секунди.

Використання `setSpeed()` з від'ємним значенням означає обертання в зворотному напрямку. Значення від `0` до `255` відповідає потужності обертання, де `0` це повний стоп, а `255` - повна швидкість.
