# Перший приклад: читання температури PT100

Цей приклад показує найпростіший спосіб роботи з бібліотекою `AmperiaSTEM`:

- читання температури з датчика PT100 через EdPro Sensor,
- виведення значення в Serial Monitor,
- передавання даних на дисплей Amperia Multimeter.

## Потрібне обладнання

Для запуску прикладу потрібне таке обладнання:

1. Arduino UNO R4 WiFi,
2. EdPro Amperia Shield,
3. Qwiic-кабель для з'єднання Arduino UNO R4 WiFi з EdPro Amperia Shield,
4. EdPro Sensor з датчиком PT100,
5. USB-кабель для живлення/завантаження коду,
6. Amperia Multimeter.

## Як підключити обладнання

1. З'єднайте Arduino UNO R4 WiFi та EdPro Amperia Shield згідно з інструкцією.
2. Підключіть EdPro Sensor до роз'єму `SENSOR` на EdPro Amperia Shield.
   - У цьому прикладі ми використовуємо датчик PT100.
   - Бібліотека автоматично зчитує опис логічних сенсорів, які повідомляє підключений EdPro Sensor.
3. Щоб бачити дані на дисплеї мультиметра, підключіть Amperia Multimeter до роз'єму `MULTIMETER` на EdPro Amperia Shield.
4. Підключіть Arduino до ноутбука чи комп'ютера за допомогою USB-кабеля.
   - Не змінюйте підключення обладнання, поки воно підключене до живлення.
   - Після підключення Arduino з'явиться в системі як послідовний порт, наприклад `COM8` у Windows або `/dev/ttyACM0` у Linux.

## Як відкрити проект

1. Відкрийте Arduino IDE.
2. Виберіть `File` → `Open...`.
3. Відкрийте файл: `examples/01_GettingStarted/01_GettingStarted.ino`.

## Як завантажити код на плату

1. У Arduino IDE виберіть плату:
   - `Arduino UNO R4 WiFi`
2. Виберіть порт:
   - наприклад, `COM8`, `COM4`, `/dev/ttyACM0` тощо.
3. Натисніть `Upload`.
4. Після успішної компіляції та прошивки на платі запуститься код.

## Як відкрити Serial Monitor

Додаткову інформацію Arduino передає через послідовний порт. Щоб побачити її, зробіть наступне:

1. У Arduino IDE відкрийте меню:
   `Tools -> Serial Monitor`
2. Встановіть швидкість передачі:
   - `115200`
3. Після відкриття Serial Monitor зачекайте, поки програма виведе дані.

Приклад виводить дані так:

```text
Starting Amperia STEM Framework...
System Ready!
Precise Temperature: 21.55
Precise Temperature: 21.60
...
```

Тобто:

- стартове повідомлення системи,
- готовність до роботи,
- поточну температуру PT100 у градусах Цельсія.

## Що робить цей приклад

1. Ініціалізує інтерфейс зовнішнього сенсора через `sensors.begin()`.
2. Викликає `sensors.discover()` і перевіряє наявність PT100 через `sensors.findSensor("PT100")`.
3. Налаштовує передавання знайдених логічних сенсорів на мультиметр через `display.begin()`.
4. Виконує початкове читання через `display.update()`.
5. Отримує температуру PT100 через `findSensor()` і `sensor->value()`.
6. Виводить температуру в Serial Monitor.
7. Передає поточні значення на мультиметр через `display.publish()`.
8. У `loop()` викликає `display.updateIfReady()` і обробляє нові дані після сигналу DREADY.

Після успішного запуску можна переходити до інших прикладів.
