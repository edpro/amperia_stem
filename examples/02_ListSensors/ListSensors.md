# Другий приклад: перелік доступних логічних сенсорів

Цей приклад показує, як за допомогою `AmperiaSensorClient` дізнатися, які логічні сенсори повідомляє підключений EdPro Sensor:

- зчитати назву пристрою,
- отримати перелік логічних сенсорів,
- для кожного сенсора вивести назву, одиницю виміру та кількість компонентів.

Приклад лише читає метадані сенсорів і виводить їх у Serial Monitor. Значення вимірювань у цьому прикладі не зчитуються.

## Потрібне обладнання

Для запуску прикладу потрібне таке обладнання:

1. Arduino UNO R4 WiFi,
2. EdPro Amperia Shield,
3. EdPro Sensor,
4. USB-кабель для живлення/завантаження коду.

Amperia Multimeter для цього прикладу не обов'язковий.

## Як підключити обладнання

1. З'єднайте Arduino UNO R4 WiFi та EdPro Amperia Shield згідно з інструкцією.
2. Підключіть EdPro Sensor до роз'єму `SENSOR` на EdPro Amperia Shield.
3. Підключіть Arduino до ноутбука чи комп'ютера за допомогою USB-кабеля.
   - Не змінюйте підключення обладнання, поки воно підключене до живлення.
   - Після підключення Arduino з'явиться в системі як послідовний порт, наприклад `COM8` у Windows або `/dev/ttyACM0` у Linux.

## Як відкрити проект

1. Відкрийте Arduino IDE.
2. Виберіть `File` → `Open...`.
3. Відкрийте файл: `examples/02_ListSensors/02_ListSensors.ino`.

## Як завантажити код на плату

1. У Arduino IDE виберіть плату:
   - `Arduino UNO R4 WiFi`
2. Виберіть порт:
   - наприклад, `COM8`, `COM4`, `/dev/ttyACM0` тощо.
3. Натисніть `Upload`.
4. Після успішної компіляції та прошивки на платі запуститься код.

## Як відкрити Serial Monitor

Додаткову інформацію Arduino передає через послідовний порт. Щоб побачити її, зробіть наступне:

1. У Arduino IDE відкрийте меню:
   `Tools -> Serial Monitor`
2. Встановіть швидкість передачі:
   - `115200`
3. Після відкриття Serial Monitor зачекайте, поки програма виведе дані.

Вміст списку залежить від підключеного EdPro Sensor. Вивід має такий формат:

```text
AmperiaSTEM sensor list
Device: <назва пристрою>
0: <назва сенсора> | unit: <одиниця> | components: <кількість компонентів>
1: <назва сенсора> | unit: <одиниця> | components: <кількість компонентів>
...
```

Тобто для кожного логічного сенсора відображаються його назва, одиниця виміру та кількість компонентів.

Якщо Serial Monitor показує:

```text
No logical sensors were reported.
```

Це означає, що підключений EdPro Sensor повідомив, що доступних логічних сенсорів немає. 


## Що робить цей приклад

1. Ініціалізує `AmperiaSensorClient` через `sensorClient.begin()`.
2. Дає зовнішньому EdPro Sensor час завершити запуск.
3. Викликає `sensorClient.discover()` і зчитує опис доступних логічних сенсорів.
4. Виводить назву пристрою через `sensorClient.deviceName()`.
5. Перебирає логічні сенсори від `0` до `sensorClient.sensorCount() - 1`.
6. Для кожного сенсора виводить `name()`, `unit()` і `dimension()`.

Метадані зчитуються один раз у `setup()`. Щоб читати самі вимірювання, в інших прикладах використовуються `update()` або `updateIfReady()`.
