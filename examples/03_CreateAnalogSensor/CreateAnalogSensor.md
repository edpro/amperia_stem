# Третій приклад: створення аналогового сенсора

Цей приклад показує, як створити власний одновимірний сенсор за допомогою `SimpleSensor`:

- зчитати аналоговий сигнал з входу `A0`,
- перетворити код ADC на значення від 0 до 100 % повної шкали,
- передати отримане значення на Amperia Multimeter,
- вивести значення в Serial Monitor.

## Потрібне обладнання

Для запуску прикладу потрібне таке обладнання:

1. Arduino UNO R4 WiFi,
2. EdPro Amperia Shield,
3. Qwiic-кабель для з'єднання Arduino UNO R4 WiFi з EdPro Amperia Shield,
4. сенсор з аналоговим виходом або інше джерело аналогового сигналу,
5. USB-кабель для живлення/завантаження коду,
6. Amperia Multimeter.

Для першої перевірки аналоговий сигнал можна, наприклад, подавати за допомогою реостата з комплекту Amperia.

## Як підключити обладнання

1. З'єднайте Arduino UNO R4 WiFi та EdPro Amperia Shield згідно з інструкцією.
2. З'єднайте Qwiic-роз'єми Arduino UNO R4 WiFi та EdPro Amperia Shield кабелем Qwiic.
3. Підключіть вихід джерела аналогового сигналу до входу `A0`. Живлення та `GND` підключіть відповідно до схеми вашого сенсора або джерела сигналу.
4. Підключіть Amperia Multimeter до роз'єму `MULTIMETER` на EdPro Amperia Shield.
5. Підключіть Arduino до ноутбука чи комп'ютера за допомогою USB-кабеля.
   - Не змінюйте підключення обладнання, поки воно підключене до живлення.
   - Після підключення Arduino з'явиться в системі як послідовний порт, наприклад `COM8` у Windows або `/dev/ttyACM0` у Linux.

Приклад виводить дані так:

```text
Amperia analog sensor is ready.
Analog level: 24.15 %
Analog level: 24.62 %
Analog level: 25.01 %
...
```

Значення `Analog level` показує, яку частину повної шкали 12-бітного ADC становить поточне показання.

## Що робить цей приклад

1. Налаштовує `A0` як аналоговий вхід.
2. Встановлює 12-бітну роздільну здатність ADC через `analogReadResolution(12)`.
3. Повідомляє мультиметру період оновлення `160` мс через `analogSensor.setDataPeriodMs(...)`.
4. Ініціалізує `SimpleSensor` через `analogSensor.begin()`.
5. У `loop()` зчитує значення ADC через `analogRead(sensorPin)`.
6. Перетворює код ADC на відсоток повної шкали.
7. Оновлює значення сенсора і передає його на мультиметр через `analogSensor.publish(levelPercent)`.
8. Виводить поточне значення в Serial Monitor.
9. Затримує наступне вимірювання на `160` мс.

## Як працює перетворення

Для 12-бітного ADC код лежить у межах від `0` до `4095`. У прикладі використано формулу:

```cpp
const float levelPercent = 100.0f * rawValue / adcMaximum;
```

де `adcMaximum = 4095.0f`.

Тому:

- `rawValue = 0` відповідає `0 %`,
- `rawValue = 2047` — приблизно `50 %`,
- `rawValue = 4095` — `100 %`.
