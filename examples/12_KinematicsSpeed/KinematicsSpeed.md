# Дванадцятий приклад: швидкість за формулою kinematics

Цей приклад показує, як зчитувати час прольоту об'єкта через фотоворота, обчислити його швидкість і передати результат на Amperia Multimeter як віртуальний сенсор.

Логіка дуже проста: якщо відомі відстань і час, то швидкість обчислюється за формулою:

v = d / t

де:
- `d` — відстань, яку проходить об'єкт між воротами,
- `t` — час прольоту,
- `v` — швидкість в метрах за секунду.

## Потрібне обладнання

Для запуску прикладу потрібне таке обладнання:

1. Arduino UNO R4 WiFi,
2. EdPro Amperia Shield,
3. Qwiic-кабель для з'єднання Arduino UNO R4 WiFi з EdPro Amperia Shield,
4. EdPro Gate Sensor (фотоворота),
5. об'єкт, що перетинає ворота, наприклад кулька або пластина,
6. USB-кабель для живлення/завантаження коду,
7. Amperia Multimeter.

## Як підключити обладнання

1. З'єднайте Arduino UNO R4 WiFi та EdPro Amperia Shield згідно з інструкцією.
2. З'єднайте Qwiic-роз'єми Arduino UNO R4 WiFi та EdPro Amperia Shield кабелем Qwiic.
3. Підключіть EdPro Gate Sensor до роз'єму `SENSOR` на EdPro Amperia Shield.
4. Підключіть Amperia Multimeter до роз'єму `MULTIMETER` на EdPro Amperia Shield.
5. Підключіть Arduino до ноутбука чи комп'ютера за допомогою USB-кабеля.
   - Не змінюйте підключення обладнання, поки воно підключене до живлення.
   - Після підключення Arduino з'явиться в системі як послідовний порт, наприклад `COM8` у Windows або `/dev/ttyACM0` у Linux.

## Що робить цей приклад

1. Ініціалізує з'єднання з фотоворотами через `sensors.begin()`.
2. Зчитує доступні сенсори через `sensors.discover()`.
3. Знаходить сенсор часу прольоту `"Travel (S)"`.
4. Визначає відстань, яку проходить об'єкт між воротами, через константу `objectDistance`.
5. Обчислює швидкість за формулою `v = d / t`.
6. Створює віртуальний сенсор `SimpleSensor` з іменем `"Kinematics"`, `"Speed"`, `"m/s"`.
7. Публікує результат на мультиметр через `speedSensor.publish(speed)`.
8. Виводить також дані в Serial Monitor для зручності відладки.

У цьому прикладі швидкість не надходить напряму від зовнішнього пристрою. Вона є похідним значенням, яке обчислюється в коді на основі часу прольоту і відомої довжини об'єкта.
