# Чотирнадцятий приклад: використання сервомотора

Цей приклад показує, як керувати сервомотором через `AmpServo`:

- встановлювати кут `0°`, `90°`, `180°`,
- виконувати плавний розмах у межах `0..180°`,
- демонструвати базове використання серво-каналу.

## Потрібне обладнання

Для запуску прикладу потрібне таке обладнання:

1. Arduino UNO R4 WiFi,
2. EdPro Amperia Shield,
3. сервомотор,
4. USB-кабель для живлення/завантаження коду.

## Як підключити обладнання

1. З'єднайте Arduino UNO R4 WiFi та EdPro Amperia Shield згідно з інструкцією.
2. Підключіть сервомотор до каналу `SERVO` на EdPro Amperia Shield.
3. Підключіть Arduino до ноутбука чи комп'ютера за допомогою USB-кабеля.
4. Після підключення Arduino з'явиться в системі як послідовний порт, наприклад `COM8` у Windows або `/dev/ttyACM0` у Linux.

## Що робить цей приклад

1. Ініціалізує сервомотор через `servo.begin()`.
2. У циклі `loop()` послідовно переводить сервомотор у кути `0°`, `90°` і `180°`.
3. Виконує циклічний розмах між `0°` і `180°` з кроком `10°`.
4. Кожна команда виконується з паузою між переміщеннями.

Можна змінити `AmpServo servo(2)` на `servo(1)` або `servo(2)`, щоб вибрати інший сервоканал.
