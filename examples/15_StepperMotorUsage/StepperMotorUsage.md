# П'ятнадцятий приклад: використання крокового двигуна

Цей приклад показує, як керувати кроковим двигуном через `AmpStepper`:

- виконувати кроки вперед і назад,
- повертати на заданий кут,
- повертати назад на той самий кут.

Він демонструє базову роботу з кроковим двигуном і використання функцій `step()` та `stepDegrees()`.

## Потрібне обладнання

Для запуску прикладу потрібне таке обладнання:

1. Arduino UNO R4 WiFi,
2. EdPro Amperia Shield,
3. кроковий двигун,
4. USB-кабель для живлення/завантаження коду.

## Як підключити обладнання

1. З'єднайте Arduino UNO R4 WiFi та EdPro Amperia Shield згідно з інструкцією.
2. Підключіть кроковий двигун до стандартних крокових пінів на EdPro Amperia Shield.
3. Підключіть Arduino до ноутбука чи комп'ютера за допомогою USB-кабеля.
4. Після підключення Arduino з'явиться в системі як послідовний порт, наприклад `COM8` у Windows або `/dev/ttyACM0` у Linux.

## Що робить цей приклад

1. Створює об'єкт `AmpStepper stepper;`.
2. Встановлює початкову швидкість через `stepper.setSpeed(60)`.
3. У циклі `loop()` виконує:
   - `stepper.step(200)` — рух вперед,
   - `stepper.step(-200)` — рух назад,
   - `stepper.stepDegrees(90.0)` — поворот на 90°,
   - `stepper.stepDegrees(-90.0)` — поворот назад.
4. Кожна дія має коротку паузу між виконаннями.

Функція `step()` працює у кроках, а `stepDegrees()` — у градусах. Це зручно для управління точним кутом повороту, наприклад для позиціювання механізму або повороту платформи.
