# Дев'ятий приклад: пересилання сенсорних даних разом із DHT11

Цей приклад показує, як поєднати дані зовнішнього сенсора з локальним вимірюванням DHT11 і передати їх усі разом на Amperia Multimeter.

У цьому сценарії `AmperiaSensorClient` читає дані від зовнішнього пристрою, а DHT11 вимірює вологість локально. Потім обидва набори значень передаються через `AmperiaBridge` в єдиний вихід для мультиметра.

## Потрібне обладнання

Для запуску прикладу потрібне таке обладнання:

1. Arduino UNO R4 WiFi,
2. EdPro Amperia Shield,
3. Qwiic-кабель для з'єднання Arduino UNO R4 WiFi з EdPro Amperia Shield,
4. DHT11,
5. зовнішній EdPro Sensor,
6. USB-кабель для живлення/завантаження коду,
7. Amperia Multimeter.

## Потрібна бібліотека

Для компіляції цього прикладу встановіть у Arduino IDE бібліотеку `DHT sensor library`.

## Як підключити обладнання

1. З'єднайте Arduino UNO R4 WiFi та EdPro Amperia Shield згідно з інструкцією.
2. З'єднайте Qwiic-роз'єми Arduino UNO R4 WiFi та EdPro Amperia Shield кабелем Qwiic.
3. Підключіть DHT11:
   - `VCC -> 5V` або `3.3V`,
   - `GND -> GND`,
   - `DATA -> D12`.
4. Підключіть зовнішній EdPro Sensor до роз'єму `SENSOR` на EdPro Amperia Shield.
5. Підключіть Amperia Multimeter до роз'єму `MULTIMETER` на EdPro Amperia Shield.
6. Підключіть Arduino до ноутбука чи комп'ютера за допомогою USB-кабеля.
   - Не змінюйте підключення обладнання, поки воно підключене до живлення.
   - Після підключення Arduino з'явиться в системі як послідовний порт, наприклад `COM8` у Windows або `/dev/ttyACM0` у Linux.

## Що робить цей приклад

1. Ініціалізує DHT11 через `humiditySensor.begin()`.
2. Ініціалізує `sourceSensor` для читання зовнішнього сенсора.
3. Зчитує доступні сенсори зовнішнього пристрою через `sourceSensor.discover()`.
4. Додає локальний сенсор DHT11 через `bridge.addSensor("DHT11 humidity", "%")`.
5. Встановлює період оновлення для цього сенсора через `bridge.setDataPeriodMs(...)`.
6. Запускає `AmperiaBridge` через `bridge.begin()`.
7. У `setup()` робить початкове зчитування зовнішніх даних через `bridge.update()`.
8. Викликає `updateHumidity()` і передає нове значення вологості в `bridge.set(...)`.
9. Публікує все вміст через `bridge.publish()`.
10. У `loop()` перевіряє, чи є нові дані від зовнішнього сенсора, і якщо минув інтервал `humidityMeasurementPeriodMs`, оновлює вологість DHT11.

## Важлива особливість

Цей приклад демонструє комбінування двох типів даних:

- зовнішній сенсор передає свої показання через `AmperiaSensorClient`,
- локальний DHT11 додається в `AmperiaBridge` як окремий логічний сенсор,
- після цього обидва потоки даних публікуються в один і той самий мультиметр.

Тобто один проект може одночасно відображати як "власну" вологість, так і дані з підключеного зовнішнього пристрою.
